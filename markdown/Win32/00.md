# プロセス
* https://learn.microsoft.com/ja-jp/windows/win32/procthread/creating-processes
```cpp
    std::string command = "notepad";
    PROCESS_INFORMATION processInfo = {};
    STARTUPINFOA startupInfo = {};
    startupInfo.cb = sizeof(startupInfo);
    startupInfo.dwFlags = STARTF_USESTDHANDLES;
    startupInfo.hStdInput = readPipe;
    startupInfo.hStdOutput = GetStdHandle(STD_OUTPUT_HANDLE);
    startupInfo.hStdError = GetStdHandle(STD_ERROR_HANDLE);
CreateProcessA(
        nullptr,
        command.data(),
        nullptr,
        nullptr,
        TRUE,
        CREATE_NO_WINDOW,
        nullptr,
        nullptr,
        &startupInfo,
        &processInfo_
    );
```

# パイプ
* プロセスどうしで、データをやり取りするもの。名前付きパイプと、匿名パイプがある。
* https://learn.microsoft.com/ja-jp/windows/win32/ipc/pipes
```cpp
    SECURITY_ATTRIBUTES sa = {};
    sa.nLength = sizeof(sa);
    sa.bInheritHandle = TRUE;

    HANDLE readPipe = nullptr;
    HANDLE writePipe = nullptr;

    if (!CreatePipe(&readPipe, &writePipe_, &sa, NULL)) {
        OutputDebugString(L"パイプの作成に失敗したよ\n");
        return;
    }
```
